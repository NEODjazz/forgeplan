Параметры проекта
Рабочие интервалы задаются ниже. Длительность и лаг — целые рабочие минуты. 480 минут = 8 рабочих часов. Нулевая длительность задачи означает веху.


Рабочий календарь
Смещение постоянно. IANA-пояса и автоматический DST пока не поддерживаются. Ночное дежурство задавайте двумя интервалами по разные стороны полуночи.
Пример перерыва: 09:00-13:00,14:00-18:00. Исключение даты заменяет неделю и имеет приоритет над списком нерабочих дат. SNET/SNLT — начало не ранее/позднее, FNET/FNLT — окончание не ранее/позднее, MSO/MFO — точное начало/окончание. Дедлайн предупреждает, но не сдвигает задачу.
Ресурсы и доступность
100% — один полный ресурс; для команды можно указать 200% и больше. Доступность по датам заменяет базовый процент. 0% — отсутствие. Все ресурсы используют рабочий календарь проекта.

Пример: 2026-10-26..2026-10-30:50; 2026-11-02..2026-11-06:0. Границы включительно; периоды не должны пересекаться.

План, факт и стоимость
Стоимость в условных денежных единицах одной валюты. Работа — минуты. Fixed work сохраняет работу при изменении назначений; fixed units сохраняет единицы при задании работы. Персональный календарь меняет доступную мощность; он не распределяет работу автоматически.
